# tripod-ball-head-3d

A 3D-printable tripod ball head, modelled for my own use.

## Contents

- `ballhead.stl` — full assembly
- `printable/` — individual printable parts (ball with stud, socket halves, wing knob)
- `printable_step/` — same parts as STEP files for CAD editing

Designed with 3D printing in mind; no supports needed for the socket halves.
